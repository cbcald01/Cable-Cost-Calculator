# Cable Cost Calculator

**CIS 199 – Software Development I | C# Windows Forms**

## Project Overview
Developed a Windows Forms application that estimates cable installation costs based on the number of receivers, hours worked, and staff assigned, with an optional student discount.

## Features
- Calculates installation costs using labor, equipment, and a base installation fee.
- Applies an optional 10% student discount.
- Displays client information and the estimated total.
- Clears input fields for a new calculation.
