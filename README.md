# Cable Installation Cost Calculator

**CIS 199 – Software Development I | C# / Windows Forms**

## Project Overview
This Windows Forms application estimates the cost of a cable installation based on the number of receivers, installation hours, and staff assigned. It also allows the user to apply a 10% student discount. I developed the program to practice calculations, constants, user input, and event-driven programming in C#.

## Features
- Enter a client name and location.
- Calculate installation costs using a $100 base fee, $20 per staff-hour, and $40 per receiver.
- Apply an optional 10% student discount by entering 1 (or 0 for no discount).
- Display the client's information and total estimated cost.
- Clear inputs and results to start a new quote.

## Skills Demonstrated
C# · Windows Forms · Event handlers · Arithmetic calculations · Constants · User input · Currency formatting

## How to Open
1. Download or clone this repository.
2. Open `Program1Spring2025.sln` in Visual Studio on Windows.
3. Build and run the Windows Forms application (targets .NET Framework 4.7.2).
